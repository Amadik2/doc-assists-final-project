# Figures Directory

This directory contains figures for the Doc Assist documentation. The following figures need to be created:

1. `deployment_architecture.png`: A diagram showing the deployment architecture of the Doc Assist system, including the API server, UI server, and their interactions.

2. `data_processing_pipeline.png`: A diagram showing the data processing pipeline, from data collection to index building.

3. `model_components.png`: A diagram showing the key model components (retriever, generator, RAG pipeline) and their interactions.

4. `evaluation_results.png`: A chart showing the evaluation results of the Doc Assist system compared to baselines.

5. `future_work_roadmap.png`: A timeline or roadmap showing the planned future work for the Doc Assist project.

## Creating Figures

These figures can be created using diagramming tools such as:
- Draw.io (https://app.diagrams.net/)
- Lucidchart (https://www.lucidchart.com/)
- Mermaid.js (https://mermaid-js.github.io/mermaid/)
- Microsoft PowerPoint or Visio

Once created, save the figures in PNG format with a resolution of at least 300 DPI for clarity.
